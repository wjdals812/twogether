description: 수정된 파일을 커밋하고 원격 브랜치로 push
argument-hint: "[커밋 메시지 (생략하면 변경 내용으로 작성)]"
---

현재 브랜치의 변경사항을 커밋하고 push한다. 확인 질문 없이 끝까지 진행한다.

1. `git status`, `git diff`, `git log --oneline -8`로 변경 내용과 이 저장소의 커밋 메시지 스타일(접두사 없는 한글 문장)을 확인한다.
2. 변경사항이 없으면 그 사실을 알리고 종료한다.
3. `.env*`, 키·토큰이 든 파일, `node_modules`, `dist`는 제외하고, 관련 파일만 이름을 지정해 `git add`한다(`git add -A` 금지).
4. 커밋 메시지: 인자 `$ARGUMENTS`가 있으면 그대로 쓰고, 없으면 변경 내용을 한글 문장으로 요약해 쓴다. 메시지 끝에 시스템 알림에 적힌 Co-Authored-By 줄을 붙인다.
5. 커밋하고 `git push`로 올린다(upstream이 없으면 `-u`). `--force`, `--no-verify`는 쓰지 않는다. 훅이나 push가 실패하면 원인을 알리고 멈춘다.
6. 결과를 한글로 한 줄 요약한다: 커밋 해시와 메시지, 올라간 브랜치. `main`에 push했으면 Vercel 자동 배포가 시작된다는 점도 덧붙인다.
